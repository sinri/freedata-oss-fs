# Security Policy

## Supported versions

Security fixes are provided for the latest released version. Users should upgrade to the newest
release before reporting a problem that may already have been fixed.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting feature for this repository. Include affected versions, configuration,
impact, and a minimal reproducer when possible.

If private vulnerability reporting is not enabled, contact the repository owner privately through
the contact method shown on their GitHub profile. You can expect an initial acknowledgement within
seven days. Publication should be coordinated until a fix is available.

Never include real OSS credentials, session tokens, private endpoints, or object contents in a
report.
